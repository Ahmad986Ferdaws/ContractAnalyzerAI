# ContractAnalyzerAI

A lightweight Python prototype for analyzing contract text and storing analysis results locally.

## What is included

- `analyzer.py` — prepares contract text for AI-assisted analysis.
- `db.py` — stores summaries and clauses in a local SQLite database.

## Project status

This repository is an early-stage prototype. The next steps are to add a command-line or web interface, improve structured output validation, and include automated tests.

## Getting started

1. Clone the repository.
2. Create a Python virtual environment.
3. Install the project dependencies.
4. Configure the required environment variables.
5. Run the analyzer from your application or Python shell.

> Do not commit API keys, contracts, or generated database files.
