# Contributing

Thanks for your interest in improving ContractAnalyzerAI.

## Suggested contributions

- Add tests for contract analysis and database operations.
- Improve validation and error handling.
- Add a command-line or web interface.
- Document installation and usage examples.
- Review privacy and security considerations for contract data.

## Workflow

1. Fork the repository and create a focused branch.
2. Make a small, clearly described change.
3. Test the change locally.
4. Open a pull request explaining what changed and why.

Please avoid committing API keys, private contracts, SQLite database files, or other sensitive data.
